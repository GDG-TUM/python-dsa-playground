# DSA and Python Daily

My public accountability log for becoming interview-ready in Python, data structures and algorithms by mid-February 2027. One focused block every morning, one quiz every day, every solution committed.

**Start date:** Wed 28 Oct 2026 · **Goal:** finish NeetCode 150 and walk into the Andela and Safaricom assessments comfortable.

## How it works

Every day has its own folder under `weeks/`:

| File | Purpose |
|------|---------|
| `plan.md` | Exactly what to cover, with links, as a checklist |
| `quiz.md` | Closed-book self-test on what I learned that day |
| `answers.md` | Check answers here, only after attempting the quiz |
| `notes.md` | My own words: what I learned, what confused me |
| `solutions/` | My code for that day's problems |

## The daily loop

1. 5 to 8 AM: Kaggle Python lesson, W3Schools DSA page, the day's problem.
2. Take the quiz, then check the answers.
3. Fill in notes, explain the solution aloud, commit and push.
4. Sunday-style lighter day each week: keep the morning block, redo the three hardest problems, no new content.

Stuck for 25 minutes? Read a hint, close it, rewrite from memory the next day.
