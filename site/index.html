Today's challenge

Contains Duplicate

Given a list of integers, return True if any value appears at least twice; otherwise return False.

Example
Input:  [1, 2, 3, 1]
Output: True

Input:  [1, 2, 3, 4]
Output: False

Think about

  • What does checking every pair cost?
  • What changes if you keep a set of values seen so far?
  • Why is a set lookup typically faster than scanning a list?
Reveal a hint

Walk through the list once. Before adding each number to a set, check whether it is already present.
