# Resources

## Python
- [Kaggle: Python course](https://www.kaggle.com/learn/python) - 7 short lessons with exercises. Week 1 uses all of them.
- [Python docs: tutorial](https://docs.python.org/3/tutorial/) - when you want the official explanation.

## Data structures and algorithms
- [W3Schools DSA](https://www.w3schools.com/dsa/) - gentle explanations with animations.
- [NeetCode 150](https://neetcode.io/practice) - the problem list, grouped by pattern.
- [LeetCode](https://leetcode.com/) - where you submit and test your solutions.

## Habits
- 25-minute rule: stuck that long means read a hint, then rewrite from memory the next day.
- Explain every solved problem aloud before you move on.
- Redo the hardest three problems each week from a blank file.
